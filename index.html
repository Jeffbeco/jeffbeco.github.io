🤔 What is Motiff?

Motiff is a powerful yet simple tool that makes motion visible in your videos. Imagine watching a video of a park and instantly highlighting every moving person, car, or animal with a bright outline or silhouette. Or maybe you want to remove a moving object from your video entirely, like magic!

Unlike complex professional video software, Motiff is built on pure ffmpeg + Bash — meaning it's lightweight, fast, and requires zero additional downloads or dependencies. It runs beautifully on any Windows computer.

Think of Motiff as your video motion detective — it spots everything that moves, then lets you decide how to display or hide it.

📖 How to Use Motiff

🎯 Simple 3-Step Process

  1. Open Command Prompt — Press Windows Key + R, type cmd, and press Enter.
  2. Navigate to download folder — Type cd Downloads (or wherever your Motiff file is located).
  3. Run Motiff — Type motiff.bat yourvideo.mp4 and press Enter. Replace "yourvideo.mp4" with your actual video file name.

That's all! Motiff will process your video and create a new file with the motion effect applied. The output file will appear in the same folder as your original video.

🔧 Advanced Options: Motiff supports different modes. Add --highlight, --silhouette, --trace, or --erase to choose your effect. Example: motiff.bat video.mp4 --highlight

📋 Frequently Asked Questions

❓ Does Motiff work on Mac or Linux?

Motiff is designed primarily for Windows systems using batch files. However, since it uses pure Bash and ffmpeg, it can be adapted for Mac and Linux with minor modifications to the script (open the file and change the extension to .sh).

❓ What video formats are supported?

Motiff supports all major video formats that ffmpeg handles — including MP4, AVI, MOV, WMV, MKV, and more. If you can play it, Motiff can process it!

❓ Is Motiff really free?

Absolutely! Motiff is completely free and open source. Download it, use it, and even modify it to suit your needs. No hidden fees, no premium versions.

❓ Will Motiff damage my original video?

No! Motiff always creates a new output file and never touches your original video. Your precious footage stays 100% safe.

❓ I'm getting an error. What should I do?

Try the following: 1) Make sure your video file name has no spaces (use underscores instead). 2) Verify you're in the right folder. 3) Check that you're using the latest version of Motiff. If problems persist, visit the GitHub page and open an issue.
